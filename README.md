### How I like to work

- **Start with a question.** Let the research problem shape the workflow.
- **Stay close to the evidence.** Be clear about what is verified, what is inferred, and what is still unknown.
- **Leave a trail.** Keep the reasoning, negative results and next steps, so the work can be revisited and continued.
